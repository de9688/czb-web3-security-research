# CZB Web3 Security Research

Public research notes from CZB Security Lab covering Web3 security, wallet-risk analysis, phishing approval patterns, and defensive incident review.

## Scope

- Wallet and private-key exposure prevention
- Approval phishing and malicious-contract risk patterns
- Public post-incident review methodology
- Defensive research notes for crypto users and security teams
- Evidence-first writing standards for Web3 security cases

## Publication Standard

Research notes should be factual, reproducible where safe, and separated from speculation. Public writeups should avoid exposing victim-sensitive data and should never include private keys, seed phrases, credentials, exploit instructions, or live attack tooling.
